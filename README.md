# Azmmah Soft

موقع تعريفي عربي متجاوب لخدمات Azmmah Soft / Azmmah Tech.

## التشغيل المحلي

من داخل مجلد المشروع:

```bash
python3 -m http.server 8765
```

ثم افتح:

`http://localhost:8765`

## الملفات

- `index.html` — الصفحة الرئيسية RTL
- `styles.css` — الهوية البصرية والتجاوب والحركات
- `app.js` — التفاعلات البسيطة والقائمة ونسخ بيانات التواصل

## ملاحظات

- الصور الحالية محملة من Unsplash عبر روابط HTTPS داخل الصفحة.
- بيانات البريد المعروضة هي `azmmahdeveloper.com` كما وردت في المتطلبات الأصلية.
- روابط التواصل: Facebook وGitHub موجودة داخل الصفحة.
